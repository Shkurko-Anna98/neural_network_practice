# Часть 3. Многопоточная и многопроцессорная обработка

## Описание
Расширение части 2 с использованием паттерна «Producer-Consumer». Чтение файлов реализовано через потоки (`threading`), а аугментация (изменение картинок) — через пул процессов (`multiprocessing`). Результаты сравнения времени сохраняются в `performance_report.json`.

## Как запустить
Убедитесь, что виртуальное окружение активировано, и вы находитесь в корне проекта:

```bash
python -m part3_parallel.app.producer_consumer
