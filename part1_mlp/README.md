# Часть 1. Объектно-ориентированная реализация многослойного перцептрона

## Описание
Данный модуль реализует полносвязную нейронную сеть (MLP) с одним скрытым слоем на языке Python с использованием библиотеки NumPy. Управление осуществляется через консольное меню.

## Структура проекта
* `app/models.py` — класс `NeuralNetwork` (прямой/обратный проход, обучение, сохранение весов).
* `app/manager.py` — класс `DatasetManager` (загрузка CSV, нормализация, разделение на выборки).
* `app/exceptions.py` — пользовательские исключения.
* `app/utils.py` — вспомогательные функции (построение графика).
* `app/main.py` — консольное меню.
